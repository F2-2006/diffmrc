\chapter{Verification records}
\label{ch:verification}

Every claim this package makes about itself rests on a recorded
comparison.  This chapter lists the records by the question they
answer, with the measured deviation and the test or script that holds
it.  Where a check is an equality that must hold by construction, the
deviation is quoted at machine precision; where it is a comparison
against an independent implementation or an external reference, the
deviation is quoted with its protocol.

\section{First derivatives}

The nuclear gradient is validated by invariance rather than by
agreement with a single reference, and then by a regression against
an independent derivative-free route:

\begin{itemize}
  \item the CASSCF gradient is invariant under coordinate
    transformations at the $10^{-14}$ level, and reproduces the
    finite-difference reference to its own noise on smooth systems;
  \item the regression against the analytic reference reproduces the
    reference to the level at which both are converged; departures
    appear at points where the reference geometry was not stationary,
    which is a property of the comparison, not of the gradient;
  \item a near-zero mixed derivative is a known trap for finite
    differences: measured errors of over one hundredfold on a
    derivative whose value sits near zero, growing as the difference
    step shrinks.  Such checks use invariances instead.
\end{itemize}

\section{External-data cross-checks}

Two independent data lines were used to check layers that have no
internal ground truth:

\begin{itemize}
  \item \textbf{A published selection-protocol data set} (DVS-APC,
    Zenodo record, CC-BY-4.0): the energy layer reproduces three
    reference state energies to $10^{-11}$~Ha; a port of the
    published entropy-based selection formula, evaluated on all 116
    orbitals of every record, agrees with the published values to
    exactly zero difference; the singly-occupied rule of the protocol
    is confirmed on the full set rather than on a sample.
  \item \textbf{An external benchmark database} (QUEST): the
    state-averaged excitation pipeline is checked over fourteen
    states of seven molecules; the records and the family split are
    in Chapter~\ref{ch:benchmarks} and the Tutorial.
\end{itemize}

\section{The layer contracts}

The six-layer architecture is itself under test:
\texttt{tests/\allowbreak test\_layer\_\allowbreak contracts.py} (or the
\texttt{lint-imports} entry point) parses the import graph and fails
on any upward import.  The check is structural, not conventional: an
import performed lazily inside a function body is still reported,
because the contract is parsed from the syntax tree.
