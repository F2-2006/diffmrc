\chapter{Reproducing the paper}

\section{Environment}

Every reproduction script sets its own runtime environment at the top:
the five BLAS thread variables and \texttt{JAX\_PLATFORMS=cpu} before
the first JAX import, and \texttt{jax\_enable\_x64} immediately after.
A script run outside this convention may produce different timings and,
in the single-precision case, wrong numbers; the settings are quoted in
Chapter~\ref{ch:installation}.

The scripts write JSON results next to themselves (or into a
\texttt{results/} directory); the figure sources read those JSON files.
Run them from a directory with the package importable, or adjust the
path insert at the top of the script.

\section{The later result lines}

The state-averaged and benchmark lines that postdate the paper's
first draft live under the project's \texttt{code/} directory:

\begin{center}
\begin{tabularx}{\textwidth}{lX}
\toprule
Script & Result \\
\midrule
\texttt{t315 / t317 / t321} & the QUEST-subset excitation runs (with \texttt{t320} the window audit) \\
\texttt{t316} & the assembled benchmark table (reads the recorded JSON) \\
\texttt{t318} & the large-molecule single-stage protocol \\
\texttt{t306} & the first state-averaged targets, with the two-pass weights \\
\texttt{t300}--\texttt{t302} & the external selection-protocol cross-check \\
\bottomrule
\end{tabularx}
\end{center}

Each of these carries its conventions in its docstring: basis,
geometry source, window rule, state-weighting pass.  A number quoted
from one of them without those four facts is a number that will not
survive being compared with the others.

\section{Building this documentation}

The Tutorial and the Manual are xelatex documents under
\texttt{manual/}; compile each twice:

\begin{lstlisting}[language=bash]
cd manual/tutorial && xelatex tutorial.tex && xelatex tutorial.tex
cd ../manual    && xelatex manual.tex    && xelatex manual.tex
\end{lstlisting}
