\section{A benchmark walkthrough}
\label{sec:benchmark-walkthrough}

This chapter runs the package against an external reference set and
shows how to read the comparison.  The reference is the QUEST database
of vertical excitation energies; the protocol follows its geometry
convention, and the numbers below come from this project's recorded
runs.

\subsection{The protocol}

\begin{itemize}
  \item \textbf{Geometries}: the reference set's own optimized
    geometries (bohr), never re-optimized --- a geometry difference is
    not a method difference, and mixing the two makes the comparison
    unreadable.
  \item \textbf{Basis}: 6-31G throughout.  The reference set reports
    its values near the complete-basis limit, so each entry carries a
    basis-set component that this protocol does not remove.  It is
    visible in the deviations below and is the first thing to check
    when interpreting them.
  \item \textbf{Active space}: the frontier window of
    Chapter~\ref{sec:active-space}, widened to three orbitals for the
    linear two-pi and amide patterns.
  \item \textbf{State averaging}: equal-weight, with a second
    between-group pass for most systems; the three window-corrected
    systems below are quoted from a single equal-weight pass.  The
    pass difference measured at or below $0.1$~eV.
  \item \textbf{Comparison columns}: the reference set reports both
    its best estimate and its own \textsc{sc}-NEVPT2 value.  Since the
    package implements \textsc{sc}-NEVPT2, the second column isolates
    method-to-method differences, while the first additionally carries
    the reference method's own error budget.
\end{itemize}

\subsection{The runs}

Each target is a script under \texttt{code/}: \texttt{t315} (first
set), \texttt{t317} (second set), \texttt{t321} (window-corrected
re-runs), with \texttt{t316} assembling the summary table from the
recorded JSON.  A single run is a state-averaged
CASSCF with per-state NEVPT2, followed by
\texttt{sa\_nevpt2\_state\_table} and the state selection of
Chapter~\ref{sec:state-averaged}.

\subsection{Reading the table}

The $n \to \pi^*$ states --- the carbonyl and amide chromophores ---
land within about three tenths of an eV of both reference columns at
this basis, which is the accuracy band the reference set itself
assigns to \textsc{sc}-NEVPT2.  The window-corrected formamide run
reproduces the reference \textsc{sc}-NEVPT2 values to $0.02$~eV.

The $\pi \to \pi^*$ states carry a uniform positive deviation of
roughly $0.6$ to $1.5$~eV.  Window corrections reduce it (cyanogen
moves from $+1.95$ to $+1.20$ on its triplet) but do not remove it,
and the residual has the same sign across five chemically different
systems.  A uniform, one-signed residual across systems is a property
of the method or the protocol, not of the individual molecules; the
candidate explanations --- valence--Rydberg mixing at the
6-31G basis, and the multiconfigurational character of the
$\pi\pi^*$ states beyond a two-orbital window --- are discussed in
Chapter~\ref{sec:limitations}.  The honest summary of this benchmark
is a capability map: the package's minimal-space protocol is
quantitative for $n \to \pi^*$ vertical excitations and systematically
high for $\pi \to \pi^*$ ones at this basis.
